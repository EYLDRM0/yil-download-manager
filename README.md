# YIL Download Manager

A Chrome extension that finds and downloads the media on the page you are viewing.

- Website: https://eyldrm0.github.io/yil-download-manager/
- [Privacy policy](https://eyldrm0.github.io/yil-download-manager/privacy.html)
- [Terms of use](TERMS.md)
- Questions and problems: [open an issue](https://github.com/EYLDRM0/yil-download-manager/issues)

DRM-protected content and YouTube are not supported. Use the software only for content you
have the right to download.
